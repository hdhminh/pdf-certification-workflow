# Security Policy

This repository is a public documentation surface for a private software product.

## Supported Scope

Security concerns relevant to this repository include:

- accidental disclosure of private implementation details
- publication of secrets, tokens, or operational identifiers
- publication of internal-only file structures that materially weaken the private system boundary
- inclusion of real customer or production data in examples

## Reporting

If you believe this repository contains material that should not be public, report it privately to the repository owner before opening a public issue.

Suggested report categories:

- secret exposure
- internal endpoint disclosure
- credential or token leak
- customer data exposure
- release artifact exposure
- implementation detail disclosure beyond intended public scope

## Response Expectation

Reports that involve data exposure or private implementation leakage should be treated as priority cleanup items.
