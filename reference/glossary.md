# Glossary

## Operator Console

The local control surface used by an authorized operator to manage active sessions.

## Local Processing Runtime

The private local execution layer that transforms incoming PDF jobs into certification-ready output.

## Intake Workspace

The queue or record system used to submit and track document-processing jobs.

## Signing Workspace

The operator-facing environment used to finalize required digital signatures.

## Temporary Processing Route

A short-lived route made available only for the duration of an active work session.
