# Contributing

This repository accepts documentation-oriented contributions only.

## Contribution Rules

Allowed contributions:

- clarifying public documentation
- improving wording, structure, diagrams, or examples
- refining sample contracts with placeholder values
- correcting high-level product descriptions

Not allowed here:

- private source code
- runtime binaries or packaged dependencies
- implementation-specific deployment details
- secrets, tokens, endpoints, or operational identifiers
- real customer data or real processing payloads

## Review Standard

Before opening a pull request, confirm:

- the change is public-safe
- no private technology choice is exposed unnecessarily
- all examples use placeholder values
- the content explains the product without enabling direct reproduction of the internal system

## Commit Style

Recommended prefixes:

- `docs:`
- `reference:`
- `examples:`
- `templates:`

Example:

```text
docs: refine workflow and security boundaries
```
