# Code Samples

This directory contains public-safe sample code.

The goal is to show the shape of the workflow without exposing private implementation.

These samples are:

- intentionally simplified
- safe to publish
- not production-ready
- not a drop-in replacement for the private system

Included examples:

- `apps-script-intake.example.js`
- `browser-signing-flow.example.js`
- `workflow-state.example.ts`
